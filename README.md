# Form Manipulation Application

## Overview
This project is a form manipulation application that allows users to input their personal details and submit them to be displayed in a table. It uses HTML, CSS, and JavaScript to create a dynamic form that updates a table with the entered data. The application also uses Bootstrap for responsive design.

## Features
- **Dynamic Form Handling**: Collects user input for personal details and preferences.
- **Real-Time Data Display**: Submits form data to be displayed in a table below the form.
- **Responsive Design**: Utilizes Bootstrap for a responsive layout that adapts to various screen sizes.
- **Styled UI**: Includes custom styling for the form and table to improve user experience.

## Technologies Used
- **HTML5**: Structure and content of the form and table.
- **CSS3**: Styling for form layout, table appearance, and responsive design.
- **JavaScript**: Handles form submission, data processing, and dynamic table updates.
- **Bootstrap 5.3.2**: Provides responsive design and styling components.

## How to Use
1. **Fill Out the Form**:
   - Enter your First Name, Last Name, Address, Pincode, State, and Country.
   - Select your Gender by choosing one of the radio buttons.
   - Choose your preferred food items from the checkboxes.
2. **Submit the Form**:
   - Click the `Submit` button to add the form data to the table.
3. **View Data**:
   - The submitted information will be displayed in a table below the form.
4. **Reset Form**:
   - The form will reset automatically after submission.

## Project Structure
- `index.html`: Contains the HTML structure of the form and table.
- `style.css`: Defines the styling for the form, table, and responsive design.
- `script.js`: Handles the form submission and updates the table with the submitted data.

## Responsive Design
- The form and table are designed to be responsive using Bootstrap and custom media queries, ensuring they look good on both desktop and mobile devices.
